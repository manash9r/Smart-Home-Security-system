# Smart-Home-Security-system
A smart home security system built using ESP32-CAM for remote monitoring and intrusion detection.

What it does
Provides live video streaming through the ESP32-CAM.
Uses radar and proximity sensors to detect movement/intruders.
Sends instant Telegram alerts to the owner's smartphone when suspicious activity is detected.
Uses an LDR sensor for light-based monitoring.
Components

ESP32-CAM • Radar Sensor • Proximity Sensor • LDR • Wi-Fi • Telegram

This was my 4th year B.Tech project, combining embedded systems, IoT, sensors, and a bit of DIY hardware.
